# パル配合ノート v120

Palworld 1.0向けの、配合記録・配合検索・配合ヒント・パル図鑑をまとめたWebアプリです。GitHub Pagesで公開し、Firebase Realtime Databaseを利用して同じルームの複数人で配合記録を共有できます。

## 現在の主な機能

- 配合記録の共同編集
- `#room=xxxxx` によるルーム単位のデータ共有
- 親2体から結果パルを調べる配合検索
- 目標パルから親ペアを探す逆引き検索
- 答えを段階的に確認できる配合ヒント
- Palworld 1.0対応のパル図鑑（299体）
- HP・攻撃・防御・種族値合計の表示・順位・並び替え
- 属性・作業適性・パートナースキル・タマゴ・移動性能・ドロップ条件などの詳細表示
- ★0〜★4のパートナースキル強化値
- 個別詳細の「作業適性」内で★0〜★4を切り替えて確認できる凝縮後の作業Lv表示
- Lv.70を含む現行1.0のレベル習得アクティブスキル、属性・威力・CT・効果表示
- 習得スキルのLv順・属性・専用技フィルター
- 作業適性の強い順 / 弱い順を使った図鑑検索
- 図鑑カードから個別詳細・比較へ直接操作（ダブルクリックで個別詳細を開く操作も維持）
- 図鑑一覧はカード表示に集中し、個別情報は詳細ページへ集約
- パル個別詳細URL `#room=xxxxx&pal=xxx`
- 最大3体のパル比較
- タマゴ登録（通常 / デカ / キョダイ → 種類選択）
- 突然変異タマゴ対応
- 確認作業、お気に入り、データ状態表示

## データと保存

### Firebase

配合記録・ルーム設定は Firebase Realtime Database を利用します。

`config.js` の `window.firebaseConfig` が共同編集用設定です。既存ルームとの互換性を維持するため、Firebaseのルーム構造や既存記録スキーマを変更する場合は事前に移行設計が必要です。

### ルームURL

同じ `room` を指定したURLを開くと同じ配合記録を共有します。

```text
#room=xxxxx
```

パルの個別詳細は `pal` を追加します。

```text
#room=xxxxx&pal=001
```

「ルームを共有」では `pal` を除外し、ルームだけを共有します。

## パルデータ

現在は Palworld 1.0 を対象とし、299体のパルを扱います。

固定データとゲーム抽出データを用途別に利用し、配合・種族値・画像・パートナースキル・作業適性・習得スキル等を構成しています。習得スキルの日本語名・説明は現行1.0抽出データを優先し、未収録時のみ既存データへフォールバックします。公開画面では利用者の判断に不要な参照元ラベルを表示せず、データの出典・検証情報はリポジトリ内の資料・実装記録で管理します。

## サイトバージョン

現在のサイト版は **v120** です。

表示用サイトバージョンは `config.js` の `window.palSiteVersion` を基準とします。リリース時はREADME・CHANGELOG・キャッシュバスターとの整合性をCIで確認します。

## 開発・検証

GitHub Actionsで以下を継続的に検証しています。

- JavaScript / Python構文
- ローカルデータ・画像・固定データ
- 配合・パル詳細の主要回帰テスト
- 凝縮★別の作業適性、Lv.70日本語習得スキル、図鑑一覧操作
- タマゴ選択、個別詳細URL、パル比較、配合ヒント
- PC / モバイル表示
- GitHub Pages互換のブラウザスモークテスト
- サイトバージョン表記の整合性

## 更新履歴

リリースごとの更新内容は [CHANGELOG.md](CHANGELOG.md) に記録します。

READMEには現在の仕様と利用・保守に必要な情報だけを掲載し、全バージョンの詳細変更を積み上げない方針です。v109以前の細かな変更履歴はGitコミット履歴から確認できます。

## リポジトリ構成（主要）

```text
index.html                 エントリポイント
config.js                  Firebase設定・サイト表示版
app-*.js                   機能別JavaScript
style-*.css                 機能別スタイル
data/                       パル・固定データ
assets/                     パル画像・アイコン等
scripts/                    データ生成・検証・ブラウザテスト
docs/                       実装プロンプト・設計記録
.github/workflows/          GitHub Actions
CHANGELOG.md                リリース履歴
```

## 更新時の基本方針

- 既存Firebaseルームと配合記録を壊さない
- 公開前に既存回帰テストをすべて通す
- サイト版を更新する
- `CHANGELOG.md` に最新版を追記する
- 必要なアセットのキャッシュバスターを更新する
- Pull Request経由で `main` に反映し、マージコミットSHAを確認する

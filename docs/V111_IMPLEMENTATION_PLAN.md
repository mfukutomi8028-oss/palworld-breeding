# v111 実装指示書 — パル詳細・用途検索・比較

## 開発チームへの指示

あなたは、ゲーム向けWebサービスを担当するプロダクトマネージャー、情報設計者、UX/UIデザイナー、フロントエンドエンジニア、データエンジニア、Firebaseエンジニア、QAエンジニアとして対応する。

既存の「パル配合ノート」について、Firebase Realtime Databaseの既存ルーム・配合記録・ユーザー設定を一切移行または破壊せず、Palworld 1.0の固定データを使うパル図鑑を強化する。実装、固定データ生成、検証、GitHub Pages公開までを一貫して完了する。

## 維持する前提

- URLハッシュ `#room=...` によるルーム分離を維持する。
- `rooms/{roomId}/records/{recordId}` と `rooms/{roomId}/meta` を変更しない。
- 既存の299体パルマスター、配合検索、発見記録モード、全パル解放モードを維持する。
- ヒント3は既存のローマ字子音方式を維持し、ムラクモ=`MRKM`、グレイシャル=`GRISYR`、最長名基準の共通枠、開示後の赤い`×`を回帰テストする。

## v111で実装する内容

1. PalDB日本語個別ページから、299体分の次の構造化データを固定JSONとして生成する。
   - パートナースキル日本語名と短い用途分類
   - 食事量、体格、レア度、売却目安、配合ランク、タマゴ
   - 歩行、走行、騎乗ダッシュ、運搬、水上移動、水上ダッシュ、スタミナ
   - 主なドロップと確率
2. パル図鑑の詳細欄へ、情報量を抑えた開閉式セクションを追加する。
3. 用途フィルターとして、騎乗可能、地上、飛行、水上、ドロップ情報ありを追加する。
4. 移動性能、食事量、レア度、売却額の並び替えを追加する。
5. 最大3体のパル比較を追加し、種族値、食事量、移動性能を横並びで確認できるようにする。
6. PCとスマートフォンの双方で横方向の表示崩れを発生させない。

## 情報掲載方針

- `Others` は攻略上の優先度が低く、内部パラメータが多いため掲載しない。
- `Active Skills` は情報量が非常に多く、現在の配合・図鑑中心の目的をぼかすためv111では掲載しない。
- `Possible Drops` は探索・牧場運用に直結するため、折りたたみ形式で掲載する。
- PalDBの長い説明文やSummaryは一括転載せず、短い名称・数値・用途分類のみ固定データへ保存する。詳細は出典ページへの導線で確認できるようにする。
- Movementは実測m/sではなく比較用内部値として明記し、騎乗不可のパルにも内部値が存在し得ることを説明する。

## 完了条件

- 固定データが299件で、英語名が重複しない。
- モコロンが食事量100、平凡なタマゴ、走行400、騎乗ダッシュ550、水上120、水上ダッシュ165、スタミナ100、パートナースキル「モコモコの盾」である。
- 新しいフィルター、並び替え、比較ダイアログが動作する。
- 既存のJavaScript構文検査、データ検査、ブラウザ回帰、画像障害時回帰、スマートフォン回帰を通過する。
- GitHub Pages公開後もFirebaseの既存ルームと記録がそのまま利用できる。

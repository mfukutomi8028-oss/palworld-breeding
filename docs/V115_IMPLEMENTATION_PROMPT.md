# v115 実装プロンプト

## 目的
パル図鑑およびパル詳細で表示している属性・作業適性のアイコン／バッジがやや小さく視認しづらいため、前回v114で修正した「属性アイコン巨大化」を再発させず、一覧性を維持したまま適度に拡大して可読性を向上する。

あわせて、パル図鑑から個別詳細ページを開いた状態で左メニューから他の機能へ移動しようとしても、詳細URLの `pal` パラメータ復元処理によって図鑑詳細へ戻されてしまう不具合を修正し、通常どおり各画面へ遷移できるようにする。

## 前提
- Firebase Realtime Database、`#room=...`、既存配合記録、配合計算、ヒント、比較保存形式は変更しない。
- v114で修正した属性アイコン150px化の回帰を起こさない。
- 作業適性・属性以外のパル画像、ドロップアイテム、パートナースキル画像のサイズは変更しない。
- PCと390px幅モバイルの双方でレイアウト崩れ・横スクロールを発生させない。
- `#room=...&pal=...` による個別パル共有URLと、URLを直接開いた際の詳細ページ復元は維持する。

## 改修要件
### 1. パル図鑑カード
- 属性アイコンを現行より一段階大きくし、アイコンと属性名を認識しやすくする。
- 作業適性アイコンとLv数値も現行より一段階大きくする。
- カードの情報密度は維持し、カード高さを不必要に増やさない。

### 2. 右側パル詳細・個別詳細ページ
- 属性アイコンを17pxから約22pxへ拡大する。
- 作業適性アイコンを約20pxへ拡大する。
- バッジの文字サイズ・余白も少しだけ増やし、アイコンだけ大きく見えて不均衡にならないよう調整する。
- パル本体画像に適用される150px指定からは引き続き独立させる。

### 3. モバイル
- 390px幅でも属性・作業適性バッジが自然に折り返すこと。
- 横方向のオーバーフローを発生させない。
- タップ対象としても見やすいサイズを維持する。

### 4. 個別詳細ページから左メニューへ正常遷移
- 現状は `#room=...&pal=...` の `pal` が残ったまま `switchView()` が実行され、その直後の詳細URL復元処理が別画面への遷移を打ち消している。
- 個別詳細ページ表示中に、左メニューから図鑑以外の画面を選択した場合は、画面遷移前にURLから `pal` のみを削除する。
- `room` パラメータは必ず維持する。
- URL書き換えによる不要な `hashchange` 再入や一瞬の画面往復を避けるため、適切な履歴APIを利用する。
- 遷移後は `is-pal-profile-open` 状態と詳細ページ用タイトルを解除する。
- パル図鑑メニュー自体を押した場合は、既存の詳細表示を勝手に閉じない。
- `#room=...&pal=...` を直接開いた場合に個別詳細が復元される既存挙動は維持する。
- 配合検索や配合記録への個別詳細内ショートカットも従来どおり動作すること。

## 目標サイズ
- 図鑑カード属性アイコン: 約20px
- 図鑑カード作業適性アイコン: 約18px
- 右側詳細／個別詳細の属性アイコン: 約22px
- 右側詳細／個別詳細の作業適性アイコン: 約20px
- ただし画面幅に応じて1〜2px程度の調整は可。

## QA
- パル図鑑カードの属性アイコンが18px以上24px以下。
- パル図鑑カードの作業適性アイコンが17px以上22px以下。
- 右側詳細の属性アイコンが20px以上24px以下。
- 右側詳細の作業適性アイコンが18px以上22px以下。
- 個別詳細ページでも同条件を満たす。
- パル本体画像は従来サイズを維持する。
- 390px幅で横オーバーフローがない。
- 個別詳細ページを開いた状態で左メニューの「配合記録」「配合検索」「ヒント」「設定」等へ遷移でき、遷移後に `pal` パラメータが残らない。
- 左メニュー遷移後も `room` パラメータが維持される。
- `#room=...&pal=...` の直接アクセスでは従来どおりパル詳細が復元される。
- v111/v112/v114の既存回帰テストをすべて通す。

# v112 実装プロンプト

あなたは、ゲーム向けWebサービスの開発経験が豊富なシニアプロダクトマネージャー、UX/UIデザイナー、情報設計者、フロントエンドエンジニア、Firebaseエンジニア、データエンジニア、QAエンジニアで構成された開発チームとして対応してください。

現在運用中の「パル配合ノート」を、既存データ・既存機能・Firebase Realtime Database・`#room=xxxxx` 方式を壊さず、日常利用での操作回数とスクロール量を減らす方向で改善してください。

## 最優先要件

1. 配合記録のタマゴ選択UIを、27個を一括表示する方式から2段階方式へ戻す。
   - 第1段階: `通常 / デカ / キョダイ` の3サイズから選択する。
   - 第2段階: 9種類のタマゴ種別から選択する。
   - 通常サイズの保存名には「通常」などの前置きを追加せず、従来の `平凡なタマゴ` 等の名称をそのまま使う。
   - デカ・キョダイは既存データと互換性のある `平凡なデカタマゴ` / `平凡なキョダイタマゴ` 等を保存する。
   - 既存のタマゴ画像、変異タマゴのロック動作、既存レコード編集時の復元を維持する。
   - 画面内に同じ画像が3回ずつ並ばないようにし、PC・スマートフォンともスクロール量を減らす。

2. パル図鑑の右側詳細から、次の配合関係一覧を削除する。
   - このルームで発見した作り方
   - このルームで発見した派生先
   - 全パル解放モード時の同等セクション（このパルを作れる配合 / このパルを親にした配合）
   これらは「配合記録」「配合検索」に責務を集約する。

3. 削除した情報の代わりに、利用者が迷わず既存機能へ移動できるショートカットを用意する。
   - このパル名で配合記録を絞り込む。
   - このパルを目標パルとして配合検索へ移動する。

## パル図鑑の情報設計

PalDBのように299個の物理HTMLを生成するのではなく、現行SPAを維持したまま「1パル=1詳細ページ相当」の深い表示を追加する。

- 一覧 + 右側クイックプレビューは維持し、素早い比較用途を壊さない。
- 右側詳細から「詳細ページ」を開けるようにする。
- 詳細ページは現行SPA内のフル幅表示とし、URLハッシュへ `pal=<Pal ID>` を追加して個別URLとして共有できるようにする。
- 例: `#room=xxxxx&pal=001`
- 直接そのURLを開いた場合もパル図鑑の詳細ページを復元する。
- ルーム共有ボタンは `pal` を含めず、従来どおりルームURLだけをコピーする。
- 詳細ページには一覧へ戻る、前のパル、次のパル、このパルを共有、このパルの配合を探す導線を置く。
- 既存の発見記録モードでは未発見パルを個別URLから露出させない。

## 詳細情報の改善

既に固定取得済みのPalDB由来データを優先的に活用し、追加スクレイピングによる回帰リスクを増やさない。

現行表示に加えて、既存JSONに保持している以下の値を「詳細ステータス」として折りたたみ表示する。

- 近接攻撃係数
- 作業速度係数
- サポート値
- 捕獲補正
- オス確率

これらはゲーム画面に直接表示されない内部比較値を含むことを明記する。

既存の以下は維持する。

- HP / 攻撃 / 防御 / 合計
- 作業適性
- パートナースキル
- 食事量
- タマゴ
- 体格 / レア度 / 売却目安 / 配合ランク
- Movement各値 / スタミナ
- 主なドロップ
- 最大3体比較
- PalDB出典リンク

Active SkillsやOthersの全面追加は今回行わない。まず詳細ページの情報設計を整え、利用頻度と視認性を優先する。

## 追加の利便性改善

- パル図鑑に「条件をリセット」ボタンを追加し、検索・属性・作業適性・用途・並び順を一括で初期化できるようにする。
- 詳細ページでも既存の比較機能を利用できること。
- モバイルで横スクロールを発生させない。
- フル詳細表示では右側パネル固有の高さ制限を解除し、通常ページとして自然に縦スクロールできるようにする。

## 非機能要件

- Firebase Realtime Databaseのスキーマ・ルーム・既存配合記録を変更しない。
- `#room=xxxxx` 方式を維持する。
- 既存の配合検索、配合ヒント、パル選択、図鑑、比較、確認作業、お気に入り、設定を壊さない。
- ムラクモ=`MRKM`、グレイシャル=`GRISYR` 等の既存ヒント仕様を回帰させない。
- PCと390px級スマートフォンをテストする。
- GitHub Pagesで動作する静的構成を維持する。

## QA / 受入条件

- タマゴ選択画面にサイズが3個、タマゴ種類が9個だけ表示される。
- デカを選び平凡なタマゴを選ぶと `平凡なデカタマゴ` が保存される。
- 通常を選び熱を帯びたタマゴを選ぶと `熱を帯びたタマゴ` が保存され、「通常」は保存名に含まれない。
- パル図鑑詳細に不要な配合関係2セクションが表示されない。
- 詳細ステータスと配合記録ショートカットが表示される。
- 詳細ページを開くと `pal` がURLに入り、閉じると `pal` が外れる。
- `#room=...&pal=...` の直接アクセスで対象パル詳細が復元される。
- 図鑑条件を1クリックでリセットできる。
- 390px幅で横方向オーバーフローがない。
- 新規テストと既存CIがすべて成功してからmainへ反映する。

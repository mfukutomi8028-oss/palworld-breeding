# v120 Implementation Prompt

## 目的
パル図鑑を「一覧で探す場所」と「個別詳細で深く見る場所」に明確に分離し、一覧の情報過多を解消する。同時に、現行Palworld 1.0の新しい習得スキルが英語へフォールバックする日本語データ不整合を修正する。

## 背景
v119で作業適性の最低Lv・想定★フィルター、右側の簡易詳細、凝縮★別作業Lv、Lv.70までの習得スキルを追加した。しかし実利用では最低Lv・想定★は検索条件として優先度が低く、右側簡易詳細は情報量増加により縦横スクロールを必要とし、本来の「ぱっと見る」役割を失った。また、習得Lvの参照元だけ現行抽出データへ更新し、日本語名・説明が旧データのままだったため、新規スキルが英語表示になるケースが残った。

## 実装要件
1. パル図鑑一覧から「最低Lv」「想定★」フィルターを除去する。作業適性による絞り込み、作業Lvの強い順 / 弱い順は基礎値で維持する。
2. 一覧右側の簡易詳細を廃止し、一覧時は詳細描画とモバイル簡易詳細モーダルを起動しない。
3. 各パルカードに常時見える「詳細を見る」「比較に追加 / 比較から外す」を配置する。既存のダブルクリックで個別詳細を開く操作は維持する。
4. 個別詳細ページは従来どおり `#room=...&pal=...` で開き、共有・前後移動・比較・配合検索を維持する。
5. 「作業適性の★強化」は独立した右側カードから外し、個別詳細上部の既存「作業適性」セクション内へ移動する。基礎作業適性と凝縮後作業Lvの関係が一続きで理解できるUIにする。
6. 習得スキルの日本語名・説明は、現行Palworld 1.0抽出 `DT_SkillNameText` / `DT_SkillDescText` を第一参照元とし、既存データをフォールバックにする。抽出JSONのCompositeDataTable形式を正しく処理し、ゲーム内マークアップは公開表示用に除去する。
7. レヴィドラLv.70 `SeaGush / Geyser Gush` が「水柱噴出」、説明が「敵のいる地点とその周囲に 大量の水柱を噴出させる。」として表示されることを回帰テストする。

## 維持するもの
- Firebase Realtime Databaseのルーム構造・既存配合記録
- パル比較（最大3体）
- 個別詳細URLと共有
- ダブルクリックで詳細を開く操作
- Lv.70までの習得Lvデータ、威力、CT、属性、専用技フィルター
- 凝縮★0〜★4の作業Lv計算そのもの

## 変更しないもの
- 配合ロジック
- タマゴ・突然変異・確認作業・お気に入り
- パル299体の基本データ構造

## 品質基準 / 検証
- 一覧に `paldexWorkMin` / `paldexWorkStar` が存在しない。
- 一覧時に `#palDetail` が表示されず、パル1回クリックでも詳細モーダルを開かない。
- 全表示カードに詳細・比較アクションが存在する。
- 詳細ボタンとダブルクリックの双方で個別詳細へ遷移できる。
- 比較ボタンから既存比較トレイへ追加できる。
- 作業★UIが既存「作業適性」セクション内にある。
- レヴィドラLv.70が日本語名・日本語説明で表示される。
- 390px幅で水平オーバーフローを発生させない。
- 既存回帰テストとv120専用Playwrightテストを通過させる。

## リスク
既存の簡易詳細は複数世代のラッパー関数から描画されるため、CSSで隠すだけでは不要な外部データ取得やモバイルモーダル起動が残る。最終ラッパーで一覧時の詳細描画自体を抑止し、個別詳細モードでは従来チェーンをそのまま実行すること。

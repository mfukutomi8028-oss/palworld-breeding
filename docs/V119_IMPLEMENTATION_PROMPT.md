# V119 Implementation Prompt

## 目的
Palworld 1.0のパル図鑑を、実際の育成・拠点運用で判断しやすい情報設計へ更新する。特に凝縮★による作業適性、Lv.70までの習得スキル、詳細画面の情報密度、図鑑フィルターの操作性を改善する。

## 必須要件
1. 「条件をリセット」が用途フィルターと重ならないレスポンシブなツールバー構成にする。
2. 作業適性は★0〜★4を選択でき、各ランクで到達する実Lvを表示する。
3. 図鑑検索でも想定★を指定し、そのランクの作業Lvで最低Lv・昇順・降順を評価する。
4. 習得スキルは現行1.0抽出データを使用し、Lv.35専用技・Lv.70技を欠落させない。
5. 詳細画面は上段2カラム（左: パートナースキル、右: ★別パートナー効果 + 作業適性）、下段全幅に習得スキルとする。
6. 習得スキルはLv順・属性・専用技で絞り込める。
7. 利用者に不要な出典・内部検証ラベルは公開UIから除去する。出典情報はコード・ドキュメントで保持する。
8. 既存の配合記録、Firebaseルーム、比較、個別URL、タマゴ、モーダル背景クリック等を壊さない。

## 作業適性の凝縮計算
- ★0: 基礎値。
- ★1〜★3: 基礎Lvが高い作業から順番に1段階ずつ上げる。保有作業数が3未満の場合は優先順を巡回する。
- ★4: ★3までの上昇に加えて、保有する全作業適性を+1する。
- 最大Lvは10。
- 同Lvの場合は既存パルデータ内の作業順を安定順序として扱う。

## データ
- レベル習得表は `Dhampyru/Palworld-Extracted` のPalworld 1.0抽出 `DT_WazaMasterLevel.json` を固定コミット参照する。
- パートナースキル★別値、技名、日本語説明、威力・CTの既存データ結合は維持する。

## 検証
- デスティング: ★3で伐採Lv.4 / 採掘Lv.7、★4で採掘Lv.8となること。
- デスティング: Lv.1/7/15/22/30/35/40/50/70を表示し、Lv.70ダークウィスプが出ること。
- パートナースキル: 防御5/6/7/8/10%、雷ドロップ40/50/60/70/80%。
- 条件リセットと用途が交差しないこと。
- 習得スキルが上段概要の下に全幅で配置されること。
- 390px幅で水平スクロールが発生しないこと。
- 既存回帰テストとGitHub Pages検証が成功すること。

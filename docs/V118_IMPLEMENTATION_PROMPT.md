# V118 Implementation Prompt

## 目的
Palworld 1.0のパル図鑑を、配合確認だけでなく「育成後の強さ」と「拠点適性」を判断できる実用的な図鑑へ拡張する。

## 対象
- パル詳細の凝縮★0〜★4情報
- レベル習得アクティブスキル
- 種族値順位
- 作業適性の検索・並び替え
- dialogの背景クリック閉じる動作
- GitHub Pagesのリリース検証

## 必須要件
1. パートナースキルは★0〜★4の数値を、Palworld 1.0対応データから取得して表形式で表示する。
2. 作業適性は自然値を基準に、★1〜3は既存適性のうち1項目が強化されるため固定値を捏造しない。★4は全作業適性+1として表示する。
3. 習得スキルはパルごとの習得Lvと、属性・威力・CT・効果を表示する。未収録値は推測しない。
4. 種族値はHP・攻撃・防御・合計それぞれに、同値同順位の図鑑内順位を表示する。
5. 作業適性は選択対象または最高作業Lvを基準に、強い順 / 弱い順へ並び替え可能にする。非対応パルは常に末尾とする。
6. 最低作業Lvフィルターを追加し、選択中の作業適性を一覧カードで視覚強調する。
7. dialog背景クリックは、既存の閉じるボタンがある場合はそのclick処理を呼び出し、同じキャンセル動作を保証する。
8. Firebaseの既存データ構造、ルーム共有、配合記録、ネタバレ制御は変更しない。

## データ品質
- PalDBの既存1.0固定データを維持する。
- パートナースキル★別値は1.0向け抽出データを参照する。
- 習得Lvと日本語名・効果説明はPalworld 1.0のゲーム抽出データを参照し、威力・CTは1.0 Active Skillsデータを照合する。
- 内部技IDから英語技名へ対応付ける用途にのみPalEditの1.0英語名辞書を利用し、旧習得表は採用しない。
- 日本語名データがない新技は英語名へフォールバックし、誤訳を生成しない。

## UI/UX
- 既存のダークUIとカード設計へ統合し、追加情報が詳細ページを圧迫しすぎないこと。
- ★4、上位順位、選択中作業適性など判断に重要な値を視覚強調する。
- モバイルでは横スクロール可能な表とし、ページ全体の横はみ出しを発生させない。

## 検証
- `node --check` で変更JSの構文を検証する。
- `scripts/validate-site-version.mjs` でv118のREADME/CHANGELOG/index/config整合を確認する。
- 既存のv110〜v117検証スクリプトを可能な範囲で継続実行する。
- GitHub Pages workflowは特定旧バージョンをハードコードせず、現行版を検証する。

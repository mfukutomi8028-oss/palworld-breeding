# v113 実装プロンプト・受入条件

## 目的

既存の Firebase Realtime Database、`#room=...` の共有方式、登録済み配合記録、v111/v112 のパル図鑑・比較・個別詳細URLを維持したまま、パル図鑑を「文字を読む画面」から「見て素早く判断できる図鑑」へ改善する。

## 必須要件

1. パル図鑑右側詳細の「詳細ページ」「比較に追加」を、パル名・属性に近い上部の主要アクションとして目立たせる。
2. 個別詳細ページでも、比較・配合検索・共有など頻用操作を上部にまとめる。
3. パートナースキルは分類タグを残しつつ、日本語の具体的な効果説明とスキルアイコンを表示する。
4. パル図鑑カードはシングルクリックで従来どおり右側詳細、ダブルクリックで `#room=...&pal=...` の個別詳細を開く。
5. PalDBで確認できるアイコンを調査し、取得が安定しているものを表示する。
   - 属性
   - 作業適性
   - パートナースキル
   - ドロップアイテム
6. アイコン取得失敗時もテキスト情報を残し、UIや操作を壊さない。
7. モバイルで横スクロールを発生させない。

## データ設計

既存 `data/pal-details-v1.json` は変更せず、補助スナップショット `data/pal-ui-v113.json` を追加する。

理由:
- 既存v111の固定データとテストを壊さない。
- 表示用データを任意拡張として読み込める。
- 外部取得に失敗してもv112までの機能へ自然にフォールバックできる。

補助データには次を持つ。

- `partnerSkill.name`
- `partnerSkill.description`
- `partnerSkill.icon`
- `drops[].item`
- `drops[].quantity`
- `drops[].probability`
- `drops[].icon`
- `elementIcons`
- `workIcons`

## UI設計

### 右側プレビュー

パル画像・名称・属性の直下に主要アクションバーを置く。

- 主: 詳細ページ
- 副: 比較に追加 / 比較から外す

従来の情報下部にある同種ボタンは非表示にし、操作場所を一本化する。

### 個別詳細ページ

ヒーロー直下に次を置く。

- 比較に追加 / 比較から外す
- このパルの配合を探す
- 共有

既存の「前へ / 次へ / 図鑑一覧へ」はナビゲーションとして維持する。

### パートナースキル

- スキルアイコン
- スキル名
- 既存分類タグ
- 日本語効果説明

の順に配置する。

### アイコン

文字を削除してアイコンだけにするのではなく、原則として「アイコン + 文字」またはツールチップ付きで意味を維持する。

## QA

- 299体すべてにパートナースキル説明があること。
- 299体すべてにパートナースキルアイコンがあること。
- 取得済みドロップ行すべてにアイコンがあること。
- 属性9種・作業適性12種のアイコン定義を検証すること。
- モコロンで以下を自動検証すること。
  - モコモコの盾
  - 詳細説明に「盾」「羊毛」
  - スキルアイコン `_005.webp`
  - 羊毛 数量1–3 / 確率100%
  - 羊毛アイコン
- シングルクリックとダブルクリックを両立すること。
- v111、v112の既存ブラウザテストを継続実行すること。
- 390px幅で横オーバーフローがないこと。

## 非変更範囲

- Firebase schema
- room ID / URL共有方式
- 既存の配合記録
- 配合計算ロジック
- ヒント機能
- 比較データの保存形式
